Setiap tugas disimpan dalam folder masing-masing berdasarkan modul agar lebih mudah dicari dan dipelajari kembali.

## Teknologi

- C++
- Code::Blocks
- Git & GitHub

## Menjalankan Program

1. Clone repository ini.
2. Buka folder tugas yang ingin dijalankan.
3. Buka file project melalui Code::Blocks, atau buat project baru jika belum tersedia.
4. Pastikan seluruh file source dan header yang dibutuhkan sudah dimasukkan.
5. Compile dan jalankan program.

## Tujuan Repository

Repository ini digunakan untuk menyimpan hasil pengerjaan tugas praktikum Struktur Data selama perkuliahan. Selain sebagai dokumentasi, kode di dalamnya juga bisa digunakan kembali untuk mempelajari materi dan melihat perkembangan pengerjaan setiap modul.
